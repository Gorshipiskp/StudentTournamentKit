# Student Tournament Platform — продукт

> Согласованное видение владельца · калибровка 2026-08-11.  
> Код пока не реализован.

---

## В двух минутах

**Название:** Student Tournament Platform (STP). На overlay — обязательный едва заметный watermark (угол экрана).

**Кто пользователь:** организаторы турниров; режиссёр/оператор; судья; комментаторы (1–2); зрители на Twitch.

**Что решаем:** платформа для проведения **дистанционных** турниров по CS2 (5×5) с полупрофессиональной трансляцией: overlay, управление OBS, сетка, результаты, GOTV-запись, workflow судьи. Продукт **нейтральный** — не привязан к университету, факультетам или BestTvGU.

**Что НЕ делаем сейчас:** BestTvGU-интеграция, публичный сайт для зрителей, мобильное приложение, другие игры, ставки, Faceit, продвинутый античит.

**Подход к разработке:** не «MVP-заглушка», а **продукт вертикальными срезами** — каждый срез даёт рабочий кусок end-to-end.

---

## Цель успеха

| Горизонт | Критерий |
|----------|----------|
| Первый рубеж | Внутренний тестовый матч 5v5: overlay, панель режиссёра, GOTV-запись |
| ~6 месяцев | Один **полный турнир** end-to-end без костылей |
| Дальше | Второй турнир разворачивается за часы, не дни |

## Пользователи и роли на эфире

| Роль | Устройство | Задача |
|------|------------|--------|
| **Организатор** | Браузер → VPS платформы | Создание турниров, команд, матчей; настройка брендинга |
| **Режиссёр = оператор** | **Один ноутбук**: CS2 spectator + OBS + браузер (панель) | Сцены OBS, overlay, камера (GOTV auto-director + hotkeys), эфир |
| **Судья** | Телефон, веб-панель (invite-ссылка) | Запрос проверки, пауза, forfeit или продолжение |
| **Комментаторы** | Браузер (1 или 2 человека), удалённо | Production video **из браузера**, low latency; аудио — Voicemeeter/микшер вне платформы |
| **Игроки** | CS2 клиент | Подключение к серверу на VPS |

**Вне платформы (организатор настраивает сам):** стримы игроков для судьи на дистанционных турнирах (Discord, 480p/15fps).

---

## Workflow судьи

1. Судья нажимает **«Запрос проверки»** → система фиксирует (можно отменить до паузы).
2. В **начале следующего раунда** (момент закупки) — автоматическая пауза на game server.
3. **Режиссёр** и **комментаторы** видят статус («тех. перерыв» / «проверка»).
4. Итог: **техническое поражение** (forfeit) одной команде **или** «всё в порядке» → матч продолжается.

## Турнирная логика

| Параметр | Решение |
|----------|---------|
| Игра | **Только CS2** на турнир (одна игра при создании) |
| Формат матчей | Настраивается на турнир (BO1/BO3/BO5 и т.д.) |
| Сетка | **Single elimination**; при нечётном числе команд — **админ решает структуру вручную** |
| Регистрация | Админ создаёт команды и игроков вручную |
| Состав | 5 игроков; тренер опционально |
| Карты | Выбираются **вручную** на матч |
| Расписание | Время матчей задаёт админ |
| Статусы турнира | Черновик → live → завершён |
| Состояния матча | Синхронизированы с game server (MatchZy + обёртка API) |
| Knife round | Как настроит MatchZy |
| Статистика | Счёт + статистика игроков, если сервер отдаёт |
| Параллельные турниры | **Да** — много турниров на инстансе организатора |

## Production и трансляция

| Параметр | Решение |
|----------|---------|
| Уровень эфира | **Полупро**: intro, представление команд, матч, переходы, ожидание, победитель, реплеи (если возможно) |
| OBS | Локально на ноутбуке режиссёра; **все основные сцены** из панели (OBS WebSocket) |
| Overlay | Автоматика с game server + **ручной override** режиссёра; Browser Source с VPS платформы |
| Автокамера | **GOTV auto-director** CS2 + hotkeys на крайние случаи (отдельного оператора нет) |
| Захват игры | CS2 spectator на **том же ноутбуке**, что OBS |
| Платформа стриминга | **Twitch** (stream key вручную в OBS) |
| Задержка эфира | **Два потока:** live WebRTC комментаторам; публичный Twitch с **OBS Stream Delay** (~90–120 с, настраиваемо). FFmpeg delay в Agent — только fallback v2 |
| Запись | **GOTV/demo обязательно**; запись OBS не обязательна |
| Аудио комментаторов | Voicemeeter / микшер → OBS (вне платформы) |
| Язык UI | Только русский |
| Брендинг | Нейтральная платформа; логотипы/цвета на уровне турнира; watermark STP обязателен |

## Инфраструктура (продуктовый уровень)

| Компонент | Где живёт |
|-----------|-----------|
| Платформа (API, overlay, панели) | **Временный VPS** на турнир (пока поднимается вручную) |
| База данных | **Постоянный MySQL VPS** на организатора (все турниры, BLOB для медиа) |
| CS2 server | **Временный VPS** на турнир (пока вручную), регион RU/EU |
| OBS + CS2 + director agent | **Ноутбук режиссёра** (локально) |
| Интернет | Обязателен; overlay с VPS через интернет — **приемлемо** |

**Модель инстанса:** у каждого организатора свой инстанс + своя MySQL. Экспорт/импорт БД не приоритет (БД на отдельном VPS).

**Обновление платформы:** `git pull` на VPS.

## BestTvGU

Интеграция **после** готовности STP. Сейчас: публичный **API** для виджетов (сетка, расписание, статистика) — реализацию UI на стороне BestTvGU передаёт владелец их тимлиду.

---

## Non-goals (явно)

- Мобильное приложение
- Ставки, Faceit
- Kubernetes, микросервисы «на вырост»
- Продвинутый античит (достаточно VAC + доверие + судья)
- **Другие игры** — не в планах; абстракция только там, где не мешает CS2
- Мультиигровые турниры
- Публичный сайт для зрителей (вместо этого — API + Twitch)

---

## Главные боли, которые продукт должен закрыть

- Слишком много ручной работы в OBS
- Нестабильный game server
- Некрасивый / лагающий overlay
- Сложная координация людей на эфире
- Долгая подготовка турнира
- **Крутой имидж** трансляции
