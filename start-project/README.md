# Стартовый набор ИИ-команды

> **Назначение:** скопировать содержимое `start-project/` в корень **нового** репозитория и дать агенту команду:  
> *«Изучи `start-project/README.md` и `SETUP.md`, разверни структуру команды под этот проект».*

Это **портативная версия** процессов BeOnBoard: роли, спринт, токены, философия разработки, skills и правила Cursor — **без привязки к конкретному продукту**.

### Важно: набор «тяжёлый» по замыслу

Шаблон **заточен под сложную техническую и инженерную разработку**: монорепо, несколько каналов (web / API / mobile / bot), длинные эпики, отдельные роли на security, scout, дизайн, QA, DevOps и т.д.

**В новом проекте не обязано понадобиться всё.** Бери только то, что оправдано масштабом:

| Масштаб проекта | Обычно достаточно |
|-----------------|-------------------|
| Небольшой / solo / MVP | `workers/developer/` + `team-lead/` (или один агент), упрощённый `AGENTS.md`, без scout и оркестратора |
| Средний продукт | + `tester/`, `documentarian/`, `tasks/`, `overview/`, базовый sprint |
| Крупный / платформа | полный набор ролей, `tech-overview/`, CODE_CHANGE_BOARD, runbook N/M, PTM, designer |

Перед bootstrap **согласуй с владельцем профиль** ([SETUP.md](SETUP.md) § «Масштаб команды»). Лишние папки ролей можно не создавать — лучше меньше, но живых артефактов, чем 14 пустых IDENTITY «на будущее».

## Быстрый старт (владелец)

1. Скопируй `start-project/*` в корень целевого репо (или оставь как `start-project/` и попроси агента **перенести** по SETUP).
2. Заполни в [SETUP.md](SETUP.md) блок **«Профиль проекта»** (имя, стек, пакеты).
3. Открой чат **Team Lead** — вставь промпт из [AGENTS.md](AGENTS.md) § Team Lead.
4. Напиши: `Погнали спринт: <цель одной фразой>`.

## Быстрый старт (агент в пустом проекте)

```text
Задача: развернуть ИИ-команду по start-project/.

1. Прочитай start-project/README.md, SETUP.md, PHILOSOPHY.md, workers/README.md, workers/ROLES.md.
2. Создай в корне репо структуру из docs/PROJECT-STRUCTURE.md (подставь имя проекта из SETUP).
3. Скопируй/адаптируй workers/, .cursor/skills, .cursor/rules — замени {{PROJECT_NAME}} и пути пакетов.
4. Создай overview/product.md и PROJECT.md — черновик по ответам владельца или по коду.
5. Заполни workers/sprint/CURRENT.md — первый спринт «Bootstrap команды».
6. Отчёт: дерево папок + что осталось уточнить у владельца.
```

## Отличие от «просто AGENTS.md»

| Только AGENTS | Этот набор |
|---------------|------------|
| Роли в одном файле | Папка `workers/<role>/` с IDENTITY, WORKLOG, CURRENT_TASK |
| Нет спринта | Очередь оркестратора, статусы, журнал |
| Нет экономии токенов | TOKEN-HYGIENE, L0/L1/L2, 1 чат = 1 промпт |
| Нет энциклопедии | Scout + CODE_CHANGE_BOARD → tech-overview |
| Нет философии поставки | PHILOSOPHY + runbook «минимум промптов» |
