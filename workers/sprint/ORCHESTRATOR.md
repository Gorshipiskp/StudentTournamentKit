# Оркестратор спринта

> Team Lead ведёт **очередь** в [CURRENT.md](CURRENT.md). Владелец открывает только `ready`.

---

## Для владельца

| Фраза | Действие |
|-------|----------|
| `Погнали спринт: <цель>` | Новая волна |
| `Статус очереди — кого открыть?` | Список ready |
| `Закрой спринт <ID>, новый фокус: …` | Ротация спринта |

После открытия вкладки:

```text
Очередь: workers/sprint/CURRENT.md — твоя строка `<slug>`. Выполни, обнови статус и журнал.
```

---

## Статусы

| Статус | Значение |
|--------|----------|
| `pending` | Ждёт зависимости |
| `ready` | Можно открывать вкладку |
| `running` | Агент в работе |
| `done` | Готово + журнал |
| `blocked` | Нужен другой slug |
| `skipped` | Не в этом спринте |

Переходы: `pending` → `ready` → `running` → `done`.

---

## Для Team Lead

При «Погнали спринт»:

1. Обновить **Фокус** и таблицу очереди
2. `ready` только при выполненных зависимостях
3. Блок **Сейчас открыть вкладки** (1–3 slug)
4. Ответ владельцу: цель + кого открыть

После `done` волны — разблокировать следующую без ожидания.

---

## Журнал

1–3 строки на событие. Top-60 в CURRENT; старше → `archive/`.
