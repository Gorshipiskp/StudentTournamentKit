# apps/dashboard — Режиссёр + админ турниров

Svelte + Vite.

**UI:** токены BestMomentsMaker ([`packages/ui-tokens`](../../packages/ui-tokens)) — near-black · bone · amber · Sora.

| Маршрут | Назначение |
|---------|------------|
| `/director/{matchId}` | Панель режиссёра: **сцены** (1–6), предупреждения, дополнительно — табло / задержка / журнал |
| `/admin` | Вход организатора, список турниров |
| `/admin/tournaments/{id}` | Команды |
| `/admin/tournaments/{id}/bracket` | Сетка + **Репетиция** / локальный сервер + ссылки |
| `/admin/tournaments/{id}/branding` | Лого и цвета (необязательно) |

Управляет эфиром **только через Platform API** (сцены, override overlay, health, статусы).  
OBS напрямую не трогает (A8) — это зона `apps/director-agent/`.

Блок **Состояние эфира** читает `GET /api/v1/matches/{id}/health` (poll ~2 с).  
Если агент offline — на экране понятная подсказка запустить Agent (`--fake-obs` для GATE).  
Контракт: [`docs/BROADCAST-HEALTH.md`](../../docs/BROADCAST-HEALTH.md).

**Журнал действий** — `GET /api/v1/matches/{id}/audit` (публичное чтение для панели режиссёра).  
После смены сцены / override список обновляется сразу; судья и старт матча подтягиваются poll’ом.

## Admin: как провести турнир

Навигация: слева на широком экране, сверху на телефоне — **Турниры → Команды → Сетка → Оформление**.  
Фокус на действиях; длинные подсказки и задержка эфира — в «Дополнительно».

1. **Войти** на `/admin` (логин/пароль из `.env`).
2. **Создать** турнир → при необходимости **Опубликовать**.
3. **Команды** — минимум 4; внизу кнопка «К сетке».
4. **Сетка** — создать (4 или 8), выбрать пары. У полной пары — блок **Запуск**.
5. **Репетиция** или **Локальный сервер** → **Ссылки** → при рассинхроне табло: **Синхронизировать**.
6. **Данные для OBS** → скопировать **Сервер** и **Токен** в OBS (сервис WHIP) → начать трансляцию.
7. **Оформление** — по желанию.

Ошибки — тосты.

Ссылки из admin (origins в `.env`):

| Переменная | По умолчанию |
|------------|----------------|
| `STK_DASHBOARD_ORIGIN` | `http://127.0.0.1:5174` |

```powershell
cd apps/dashboard
npm install
npm run dev
```

- Режиссёр: `http://127.0.0.1:5174/director/<matchId>`
- Админ: `http://127.0.0.1:5174/admin`

### Fake-старт матча (GATE)

На экране сетки у узла с `match_id`: **«Репетиция»** → `POST /api/v1/matches/{id}/start`  
Статус → `live`, сцена `ingame`, `game_server_id=srv_fake` если пусто. **Без** live CS2 VPS.

**«Ссылки»** → judge + commentator invites + URL режиссёра (копирование одним кликом).

Vite проксирует `/api` на `http://127.0.0.1:8000`.

## Что на экране режиссёра

| Блок | Действие |
|------|----------|
| Шапка | статус матча, счёт, «состояние эфира», возраст опроса, ссылка overlay |
| **Сцена эфира** | кнопки с русскими именами → `PATCH .../production`; клавиши **1–6**; нижняя панель всегда под рукой |
| **Состояние эфира** | health по компонентам; фильтр «Только проблемы» |
| **Правка табло** | временные имена/счёт → `POST .../overlay/override` (при открытии — текущие значения) |
| **Задержка Twitch** | чек-лист Stream Delay (сохраняется в sessionStorage на матч) |
| **Журнал** | audit лог матча с фильтром по роли |

Опрос статуса ~2 с. OBS меняет только Director Agent.
