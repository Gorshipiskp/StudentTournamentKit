# apps/director-agent — Локальный агент режиссёра

Windows-агент на ноутбуке режиссёра: OBS WebSocket v5, WebRTC publish комментаторов, reconcile desired↔actual сцен.

**Статус:** заготовка (runtime — Production Slice).

Единственный канал управления OBS (инвариант A8). Platform API агент не обходит.
