# Student Tournament Platform — согласованное видение

> Полный лог калибровки с владельцем · 2026-08-11.  
> Источник правды для product и architecture. Обновлять при изменении решений владельца.

---

## 1. Идентичность продукта

| Поле | Значение |
|------|----------|
| **Название** | Student Tournament Platform (STP) |
| **Репозиторий** | BestCSTournaments |
| **Позиционирование** | Нейтральная платформа турниров и стримов; **не** привязана к университету / BestTvGU |
| **Watermark** | Обязательный, едва заметный, угол overlay |
| **Язык UI** | Только русский |
| **Первая игра** | CS2 (5×5). Другие игры **не планируются**; не строим продукт вокруг мультигейм |

---

## 2. Команда и процесс разработки

| Поле | Значение |
|------|----------|
| **Владелец** | Организатор + техника (combo) |
| **Размер** | Solo человек + ИИ-агенты |
| **Код** | Почти полностью агенты; владелец — точечные правки максимум |
| **Приёмка** | Чеклист из ТЗ |
| **Подход** | **Не MVP** — продукт **вертикальными срезами** |
| **Первый рубеж** | Внутренний тестовый матч 5v5 (overlay, панель, GOTV) |
| **Успех ~6 мес** | Один полный турнир end-to-end |
| **Бюджет инфры** | Минимальный (дешёвый VPS на матч/турнир) |
| **Open source** | Позже |

---

## 3. Формат турниров

| Тема | Решение |
|------|---------|
| Приоритет площадки | **Дистанционный** турнир первым; LAN/клуб позже |
| Дата первого турнира | Не зафиксирована — сначала платформа |
| Формат матчей | Гибкий на уровне турнира |
| Сетка | Single elimination |
| Нечётное число команд | Админ решает структуру **вручную** |
| Регистрация | Админ создаёт команды вручную |
| Параллельные турниры | Много на одном инстансе организатора |
| Жизненный цикл турнира | Черновик → live → завершён |
| Состояния матча | Синхронизация с game server |
| Состав | 5 игроков, тренер опционально |
| Карты | Вручную на матч |
| Расписание | Вручную |
| Статистика | Игроки, если сервер отдаёт |

## 4. Роли на эфире

### Режиссёр = оператор (один ноутбук)

- CS2 spectator на том же ПК
- OBS локально
- Панель режиссёра в браузере (URL VPS платформы)
- GOTV **auto-director** + hotkeys (отдельного оператора нет)

### Судья (отдельно)

- Мобильная веб-панель, invite-ссылка
- Workflow: запрос проверки → пауза в начале **следующего раунда** (закупка) → forfeit или продолжение
- Уведомления: **режиссёр + комментаторы**
- Forfeit при подтверждении читов
- На дистанционных турнирах смотрит демки игроков в Discord — **вне платформы** (480p/15fps, организатор настраивает)

### Комментаторы

- **1 или 2** человека, удалённо
- Production video **обязательно**, low latency
- Видео **только через браузер** (WebRTC)
- Источник видео: **ноутбук режиссёра** (не VPS платформы)
- Платформа: сигналинг, статусы, доступ по invite
- Аудио: Voicemeeter / микшер → OBS (**вне платформы**)

### Игроки

- Подключение к CS2 на VPS

## 5. Production

| Тема | Решение |
|------|---------|
| Уровень | Полупро (intro, команды, матч, переходы, ожидание, победитель, реплеи если возможно) |
| OBS сцены | Управление **из панели** (WebSocket), максимальная автоматизация |
| Overlay | Авто с game server + ручной override режиссёра |
| Overlay источник | Browser Source, хостится на VPS платформы |
| Задержка Twitch | Два потока: **live** комментаторам (WebRTC); **OBS Stream Delay** (~90–120 с) на публичный Twitch. FFmpeg в Agent — fallback v2 |
| Twitch API | Не нужен; stream key вручную |
| Запись | GOTV/demo **обязательно**; OBS запись не обязательна |
| OBS опыт команды | Базовый |
| При сбое | Матч на сервере + восстановление эфира в приоритете |

### Обязательные сцены overlay / эфира

Intro · представление команд · матч · ожидание · переходы · победитель · реплеи (если возможно)

## 6. Инфраструктура

```text
VPS CS2  ←→  Ноутбук (CS2 + OBS + Director Agent + браузер)  ←→  VPS платформы
                ↓ WebRTC (live)                    ↑
         Комментаторы (браузер)              Судья (мобильный веб)
                ↓
         Twitch (delayed)
Игроки ←→ VPS CS2

MySQL (постоянный VPS организатора) ← все инстансы платформы этого организатора
```

| Компонент | Где | Жизненный цикл |
|-----------|-----|----------------|
| Платформа STP | VPS | Временный на турнир |
| MySQL | VPS организатора | Постоянный |
| CS2 | VPS | Временный на турнир |
| Director Agent | Ноутбук Windows | На каждый эфир |
| Медиа (лого, фоны) | MySQL BLOB | Постоянно |

- Поднятие VPS (платформа + CS2): **вручную** на старте
- Провайдер VPS: без предпочтений
- Регион CS2: RU / EU
- Интернет: обязателен; overlay через интернет к VPS — OK
- Обновление: `git pull`

### Установка

| Компонент | Способ |
|-----------|--------|
| Платформа на VPS | **Deploy-скрипт / installer** (Docker Compose или native — см. DECISIONS) |
| Director Agent на ноутбук | **Portable installer** (локальный сервис: OBS WebSocket + WebRTC publisher) |

## 7. Игровой сервер

| Тема | Решение |
|------|---------|
| Хостинг | Арендованный VPS |
| Плагины | MatchZy + обёртка API (не переписывать без причины) |
| Античит | VAC + доверие |
| Демо | Обязательно |
| Knife | Как MatchZy |
| Provision | Ручной на старте |

### Game adapter

- **Не** делать ставку на мультигейм SDK
- CS2-first; лёгкое разделение слоёв только где не усложняет CS2
- Один турнир = одна игра (всегда CS2 в обозримом будущем)

---

## 8. BestTvGU

- **Не в scope** текущей разработки
- После STP: публичный **API** для виджетов
- UI виджетов — задача команды BestTvGU (владелец передаёт заявку)

---

## 9. Auth и доступ

- Простые роли + **invite-ссылки** (судья, комментатор, режиссёр)
- Организаторы без глубоких IT-знаний — UI «веди за руку»

---

## 10. Non-goals

- Мобильное приложение
- Ставки, Faceit, K8s
- Продвинутый античит
- Другие игры
- Мультиигровые турниры
- Публичный сайт зрителей
- BestTvGU сейчас
- ML-автокамера (только GOTV auto-director)
- Экспорт/импорт БД (не приоритет)
- Стримы игроков для судьи внутри платформы

---

## 11. Мониторинг и логи

- Простой status dashboard в платформе
- Логи действий на уровне **матча** (пауза, forfeit, смена счёта и т.д.)

## 12. Технологический стек (зафиксирован 2026-08-11)

| Слой | Технология |
|------|------------|
| Backend | Python 3.12 + FastAPI + SQLAlchemy 2 + Alembic |
| Frontend | Svelte 5 + SvelteKit + Tailwind CSS |
| Director Agent | Go 1.22 + Pion WebRTC + obs-websocket v5 |
| БД | MySQL 8 (BLOB медиа) |
| CS2 | SteamCMD, Metamod, CounterStrikeSharp, MatchZy, **STP.Bridge** |
| Комментаторы | WebRTC в браузере + coturn (TURN) |
| Delay Twitch | **OBS Stream Delay** (v1); FFmpeg в Agent — fallback v2 |
| Deploy | Docker Compose (platform), bash + native (CS2) |

Полная спецификация: [TECH-STACK.md](TECH-STACK.md). ADR: [DECISIONS.md](DECISIONS.md) § ADR-019–024.

## 13. Уточнения 2026-08-11 (финал)

1. Комментаторов **1 или 2**, не всегда 2.
2. Другие игры **не в планах** — не инвестировать в мультигейм.
3. Комментаторы: видео **только из браузера** (WebRTC).
4. Автокамера: GOTV auto-director + hotkeys — **OK**.
5. Установщик: deploy на VPS + local Director Agent (решение команды).
6. Видео комментаторам с **ноутбука режиссёра**, платформа координирует.
