# Памятка организатора — день Alpha

> Кому: человек, который создаёт турнир и раздаёт ссылки.  
> Полный день: [ALPHA-RUNBOOK.md](../ALPHA-RUNBOOK.md) · повтор / 2-й турнир: [PRODUCTION-RUNBOOK.md](../PRODUCTION-RUNBOOK.md) · UI: [apps/dashboard/README.md](../../apps/dashboard/README.md) § «Admin».

---

## Перед стартом

1. Стенд поднят (API, админка). Проверка: `http://127.0.0.1:8000/health`.
2. Логин и пароль — из `.env` (`STK_ORGANIZER_USERNAME` / `STK_ORGANIZER_PASSWORD`). По умолчанию в примере: `organizer`.
3. Alpha: **4 команды**, сетка на выбывание. Для приёмки дня достаточно **Репетиция**.  
   Живой локальный CS2 — по желанию: register → assign → **Локальный сервер** ([LOCAL-CS2-DS](../../infra/game-server/LOCAL-CS2-DS.md), [TZ009-OWNER-SMOKE](../../workers/developer/notes/TZ009-OWNER-SMOKE.md)).

## Порядок на экране

Админка: `http://127.0.0.1:5174/admin`  
Слева (на широком экране) или сверху (на телефоне): **Турниры → Команды → Сетка → Оформление**.

| Шаг | Действие | Готово, когда |
|-----|----------|----------------|
| 1 | Войти | Виден список турниров |
| 2 | **Создать** турнир → при желании **Опубликовать** | Турнир в списке |
| 3 | Добавить **4 команды** | Внизу «К сетке» |
| 4 | **Создать** сетку (4) → выбрать команды в слотах | У пар появился блок **Запуск** |
| 5 | **Репетиция** *или* **Локальный сервер** (после assign) | Матч live |
| 6 | **Данные для OBS** → скопировать **Сервер** и **Токен** в OBS (сервис WHIP) → начать трансляцию | Комментаторы видят картинку |
| 7 | Скопировать ссылки режиссёру и судье | Ссылки ушли в чат |
| 8 | (По желанию) **Оформление** — цвет / лого | Overlay подхватывает |

Комментатору — ссылка «смотреть» из того же блока ссылок (если нужен).

## Что передать команде эфира

| Кому | Что |
|------|-----|
| OBS (картинка) | Кнопка **Данные для OBS**: поле «Сервер» → Server, «Токен» → Bearer token |
| Режиссёр | Ссылка на панель + id матча · [director.md](director.md) |
| Судья | Invite-ссылка (телефон) · [judge.md](judge.md) |
| Комментатор | Ссылка `/watch` с токеном (по желанию) |

Не публикуй invite-ссылки в открытый чат зрителей — это доступ staff.

---

## Если что-то не так

| Симптом | Что сделать |
|---------|-------------|
| Нет кнопки сетки | Меньше 4 команд или турнир не опубликован |
| Нет «Репетиция» / запуска | Слот сетки не заполнен парой |
| «Локальный сервер» ошибка | Сначала game-server + assign; не путать с репетицией |
| Ссылки пустые / битые | Проверь origins в `.env` (`STK_DASHBOARD_ORIGIN`, `STK_JUDGE_ORIGIN`, `STK_WATCH_ORIGIN`) |
| Не уверен в стенде | `.\scripts\alpha-dry-run.ps1` · [scripts/README.md](../../scripts/README.md) |

Живой игровой сервер и Twitch — не часть обязательной Alpha; см. runbook.
