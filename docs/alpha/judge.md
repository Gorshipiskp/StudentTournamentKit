# Памятка судьи — день Alpha

> Кому: судья **с телефона** (или узкого окна браузера).  
> Общий день: [ALPHA-RUNBOOK.md](../ALPHA-RUNBOOK.md) · production hub: [PRODUCTION-RUNBOOK.md](../PRODUCTION-RUNBOOK.md) · приложение: [apps/judge/README.md](../../apps/judge/README.md).

---

## Как зайти

1. Организатор присылает **invite-ссылку** (из «Ссылки для команды»).
2. Открой её в браузере телефона — отдельно логиниться не нужно.
3. Если ссылка «протухла» или пустой экран — попроси **новую** у организатора.

Не пересылай ссылку зрителям: это доступ судьи к матчу.

---

## Что делать на матче

| Когда | Действие |
|-------|----------|
| Всё спокойно | Ничего не жми; экран сам обновляет статус |
| Нужна проверка | **Запросить проверку** |
| Передумал до паузы | **Отменить проверку** |
| Идёт пауза / «тех. пауза» | Дождись кнопок решения |
| Инцидент закрыт | **Продолжить матч** *или* **Техническое поражение** (укажи команду и подтверди) |

Пауза на игровом сервере обычно срабатывает на **закупке следующего раунда**. На Fake-репетиции без живого CS2 кнопки и статусы всё равно можно пройти для приёмки.

---

## Короткий чек-лист

- [ ] Ссылка открылась на телефоне, виден матч
- [ ] «Запрос проверки» уходит без ошибки
- [ ] Итог: продолжить **или** тех. поражение — матч не «ломается»
- [ ] При сомнении — напиши режиссёру/организатору в чат staff

---

## Если что-то не так

| Симптом | Что сделать |
|---------|-------------|
| Белый экран / 401 | Новая invite от организатора |
| Кнопок нет | Подожди 2–3 секунды или обнови страницу |
| Пауза не наступила | На Fake без сервера пауза может не прийти из игры — для Alpha достаточно, что запрос и решение проходят в UI |
| Не та команда при поражении | Не подтверждай; обнови страницу и выбери снова, либо зови организатора |

Организатор: [organizer.md](organizer.md) · режиссёр: [director.md](director.md).
